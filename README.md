# drinkjimmys.com

Static site: Jimmy's Cocktails content on the Henrietta Said design (Webflow export, GSAP/Lenis animations).
No build step: deploy the repository root as a static site (Vercel: framework preset *Other*, output directory `.`).

Generated by `jimmys-henrietta/_build/build.py` in the Site Kit project; edit `content.json` there and rebuild rather than editing pages by hand.
